# Code of conduct

stele follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in this repository's issues, pull requests and reviews, and
wherever someone represents the project.

In short: be respectful and constructive, assume good faith, and keep
criticism about the work, not the person. Harassment, insults and personal
attacks are not accepted.

## Reporting

Report a problem privately to the maintainers through GitHub's private
reporting form, <https://github.com/lictor-ai/stele/security/advisories/new>,
and say it is a conduct report. For a comment or issue, you can also use
GitHub's **Report content**. As the Covenant asks, the maintainers respect
the reporter's privacy.

The maintainers decide what to do, following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
a correction, a warning, a temporary ban or a permanent ban.
